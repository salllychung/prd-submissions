# 마케팅 인사이트 자동 수집 시스템

## 문제
> 마케팅 디렉터가 매일 SNS·뉴스·업계 트렌드를 수동으로 수집하느라
> 핵심 전략 업무 시간이 줄어드는 문제를 AI 자동화로 해결한다.

- **현재 상태**: 매일 30~60분을 X(Twitter), Notion, 뉴스레터 등을 수동으로 확인하며 인사이트를 수집. 팀 공유까지 포함하면 하루 최대 1.5시간 소요. 주 5일 기준 약 7.5시간/주 낭비.
- **원하는 상태**: 매일 아침 Claude가 주요 소스에서 인사이트를 자동 수집·요약하여 5분 안에 핵심 내용을 파악. Notion에 자동 저장되어 팀과 즉시 공유 가능.
- **성공 기준**: 인사이트 수집 시간 60분 → 5분 이내 단축 (92% 절감), 주 5회 이상 자동 실행, Notion 저장 성공률 100%

## 스킬
| # | 스킬명 | 한 줄 설명 | 상태 |
|---|--------|-----------|------|
| 1 | `/my-context-sync` | Notion에서 정보 수집 → 하루 현황 문서 자동 생성 | ✅ 동작 |
| 2 | `/my-fetch-tweet` | X/Twitter URL → 트윗 번역 + 인사이트 추출 | ✅ 동작 |
| 3 | `/my-session-wrap` | 세션 종료 시 작업 정리·학습 기록 자동화 | ✅ 동작 |

## 변화 기록
- **Day 1**: "Claude Code가 뭔지 모름" → Claude와 대화하며 기본 명령 익힘
- **Day 6**: "마케팅 인사이트 수집을 AI가 자동화할 수 있다"는 것을 직접 구현
- **가장 크게 달라진 점**: 정보 수집을 '내가 직접 뒤지는 것'에서 'Claude가 요약해서 가져다주는 것'으로 전환. Notion MCP 연결로 수집 → 저장 → 공유가 원클릭으로 완성됨.
